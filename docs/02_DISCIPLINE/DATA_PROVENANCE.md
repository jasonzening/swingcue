# 数据来源与授权登记 (Data Provenance)

> 每一批进入项目的外部数据,都必须在此登记:来源、授权范围、凭证。
> 目的:上线/融资时可证明数据来源合法;这是产品能否上架的生死线。
> 登记≠已审核;所有条目在上线前由律师团队统一复核。

## 登记规范

每批新数据登记以下字段:
- **来源**:谁拍的 / 从哪获得。
- **日期**:采集或获得时间。
- **授权范围**:能否用于 ①产品开发 ②训练/校准 ③商业发布 ④再分发。
- **凭证**:书面同意(消息截图/合同/consent 表)存档路径;口头的如实标注"口头,待补书面"。
- **用途限制**:该批数据在项目中允许的用途。

## 红线提醒(见 GT_IRON_RULES 与蓝图 4.4)

- 公开知识(教学原理、文献数值)可永久当"老师"参考。
- 公开数据集(GolfDB/GolfPose 类)/ 他人视频:**不作产品参数来源或训练数据**,"用完删掉"也洗不干净。
- 飞轮数据的合法来源:**自采 + 教练在产品内拖拽标注**。
- 第三方对错标注:只筛选/交叉验证,不作真值。

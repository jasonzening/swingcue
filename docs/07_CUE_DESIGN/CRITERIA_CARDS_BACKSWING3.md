## 判据卡 1 · 头部漂移(Head Drift / Sway)

**状态:确认成立,进 Phase 2 指示器。三个中判定最可靠者。**

### 权威定义
上杆允许头部少量向 trail 侧移动,这是完成充分转肩所必需的,不是错误。但超过约 1–1.5 英寸的横移会导致击球不稳。头部不应上抬(上抬破坏转肩与脊柱角)。

### 量化阈值(带出处)
- 横移权威上限:约 1–1.5 英寸。(The Left Rough:超过 1 英寸易致击球不稳,尤其铁杆;RotarySwing 教练给学生约 1.5 英寸横移余量。)
- 换算到 SHW:1.5 英寸 ≈ 0.088 SHW。
- 竖直:头不应上抬(H-y 正向 = 上抬 = 异常)。

### 参考系
**地面绝对坐标。** 头相对画面/地面的绝对位移。横移在 face-on 是画面平面内运动,参考系正确,无需相对身体。

### face-on 可行性与置信上限
**完全可靠。** 横移不吃前缩亏。证据等级可达 Confirmed。

### 主信号 + 辅信号
- 主:`H-x`(头横移,SHW 归一。正=向目标侧,负=向 trail 侧)。
- 辅:`H-y`(头竖移。正=上抬=异常,负=下沉)。

### 检测窗口
P2→P4(takeaway 到顶点)为诊断核心。注意 P8 的竖向大峰是正常收杆,不误判。

### 分级带(遵循纲领三层)
- 🟢 绿带:|H-x| ≤ 0.088 SHW(±1.5 英寸内)。
- 🟡 黄带:0.088 < |H-x| ≤ **[待真实数据校准]** SHW。
- 🔴 红带:|H-x| > **[待真实数据校准]** SHW(明显漂移)。
- fo-wrong-4 实测:H-x 峰值 −0.408 SHW ≈ −6.93 英寸,超权威上限约 4.6 倍 → 红带,毫无争议。

### 备注
建议 v1 绿带边界直接采用权威线 0.088 SHW。黄/红分界待真实数据校准。

## 判据卡 2 · 上杆手臂弯曲(Bent Lead Arm)

**状态:确认成立(真弯,非纯投影假象),进 Phase 2 指示器。判据为双信号联合。**

### 权威定义
理想:到顶点 lead arm 应保持伸直(不僵直,是有宽度的伸展)。不应让 lead arm 在肘部塌陷,否则丢失储存的力量。行业实务多以"直/不直"定性 + 顶点目视,**无统一角度数字**。

### 量化阈值(带出处)
- lead 肩–肘–腕夹角,越接近 180° 越直。实务中 < 约 160° 起算可见弯曲。(Golf Monthly、Gears Sports 等)
- fo-wrong-4 实测顶点最弯 75.1° @ fr128 → 极端折叠。

### 参考系
**自身三点(肩–肘–腕),与地面、身体朝向无关。** 参考系正确。

### face-on 可行性与置信上限
**可测,但有前缩偏差,必须校正。** 顶点手臂指向镜头深度时,2D 夹角会被前缩天然放大(手臂直也可能显示偏弯)。因此**不能只用 A-angle 单条判**,须联合前缩校正指标,否则换个手臂直的用户 face-on 也可能压到低角度而误报。证据等级:联合信号后可达 Likely~Confirmed。

### 主信号 + 辅信号(联合判据)
- 主:`AB-angle`(肩–肘–腕夹角。180=直,<180=弯)。
- 辅:`AB-fore`(lead 上臂+前臂 2D 投影总长 / address 帧同长度之比。1.0=address 臂长,<1=前缩)。
- **联合判读规则:AB-fore << 1 且 AB-angle << 180 → 真弯;AB-fore << 1 单独出现 → 可能为视角假象。**
- fo-wrong-4 实测顶点:AB-angle=78° / AB-fore=0.705。两者皆低 → 判定真弯。(注:0.705 说明也确有前缩成分,75° 里混有真弯 + 部分投影放大,故必须联合判。)

### 检测窗口
P2→P4,重点顶点 P4。

### 分级带(遵循纲领三层)
- 🟢 绿带:AB-angle ≥ 160°(且 AB-fore 未提示纯假象)。
- 🟡 黄带:**[待真实数据校准]** ° ≤ AB-angle < 160°,AB-fore 联合确认为真弯。
- 🔴 红带:AB-angle < **[待真实数据校准]** °,AB-fore 联合确认为真弯。
- fo-wrong-4 实测 75° + 联合确认真弯 → 红带。

### 备注
判据为**双信号联合**,不可退化为单角度阈值。黄/红分界待真实数据校准。

## 判据卡 3 · 上杆转肩不足(Insufficient Shoulder Turn)

**状态:成立但为轻度(略不足,非"完全没转")。face-on 深度欠定,仅粗分级,证据封顶 Likely。**

### 权威定义
好的上杆靠肩膀转动创造宽度和幅度。判"转肩不足"应看**肩相对髋的分离(X-factor)**,而非肩的绝对角——大幅肩转本身不是问题(职业 100°+ 不罕见),配上过小的髋转才是问题。

### 量化阈值(带出处)
- 肩转目标 ≈ 90°;髋转 ≈ 45°(约肩转一半)。(Golf Digest / GolfInstruction / TPI)
- X-factor(肩髋分离)≈ 40–45° 为巡回赛平均。(TPI:骨盆 45°、肩 90° → X-factor 45°,男女职业平均均为 45°。)
- Stanford 研究:职业峰值 X-factor 约 56°(硬挥),变异仅 7.4%;业余随差点下降而偏低(新手/高差点约 46–48°)。

### 参考系
**肩相对髋(X-factor 代理),非地面。** 关键:不跟地面比。若整个人向 trail 侧后倒(头漂),肩线和髋线会一起被带偏,但两者**差值**不受整体后倒影响——后倒被扣除,剩下的才是纯粹的肩相对下盘旋转。这是提纯后的正确参考系(修正了早期"肩线缩短率"被身体侧倒污染的问题)。

### face-on 可行性与置信上限
**三个中最难。face-on 深度欠定。** 肩旋转主要发生在深度方向(绕脊柱竖轴),纯 RGB 无深度传感器,旋转本质欠定。学术两面:单视频 markerless(HRNet+DeepLabCut)可计算高尔夫旋转变量、评估熟练度(路线可行);但单相机测旋转类动作效度/信度不一致,深度估计误差与遮挡可致显著误差。
**结论:仅能做粗分级(明显不足 / 大致够),证据等级封顶 Likely。做不了"差 5°"这种细微。** 若要细微精度,需 3D 或 DTL 第二机位(未来方向)。

### 主信号 + 辅信号
- 主:`TS-xfactor`(肩线朝向 Δ − 髋线朝向 Δ,相对 address,= face-on X-factor 代理。对标权威 40–45°)。
- 辅:`TS-shoulder`(肩线自身旋转,对标 90°)、`TS-hip`(髋线自身旋转,对标 45°)。

### 检测窗口
P2→P4,重点顶点 P4。

### 分级带(遵循纲领三层 —— 仅粗分级)
- 🟢 绿带(大致够):TS-xfactor 在约 40–45° 区间。
- 🟡 黄带:**不适用细微黄带**（face-on 精度不足以支撑）。可选给"略不足"粗提示,边界待 3D/DTL 或真实数据。
- 🔴 红带(明显不足):TS-xfactor 显著低于 40°(具体线待校准)。
- fo-wrong-4 实测顶点:TS-xfactor=35°(峰值 48°)、TS-shoulder=73°、TS-hip=38°。
  - 解读:肩转 73°(目标 90°,差约 17°)、X-factor 35°(目标 40–45°,差 5–10°)= **轻度不足,非"完全没转"**。与 Jason 澄清一致("没转肩"指相对好选手的幅度不够,不是完全没动)。

### 备注
- **此判据不做精细数值反馈**,只给方向性粗提示,并明确标注置信上限 Likely。
- fo-wrong-4 上此错误为轻度;它作为"中级典型细微差距"的样本有价值,但正因细微 + face-on 欠定,**恰恰暴露了 2D 测深度旋转的精度天花板**——是纲领"按信号类型分定精度"的活例证。

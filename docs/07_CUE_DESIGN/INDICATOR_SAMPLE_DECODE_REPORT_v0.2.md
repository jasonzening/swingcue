## 1. 修正后的关键条目

### Image_20260602214121_119_1.jpg(原编号样板12位置,内容为手圈+绿带)
- **针对错误**:转换期启动顺序错误(手先动 / 身体未启动)
- **对照结构**:双人并排,X/O
- **元素(三个,Jason 亲授读法)**:
  1. 红圈+红箭头 | 锚:双手 | 语义:**时序错误**——身体未动,手先下
  2. 绿弧箭头 | 锚:髋 | 语义:**时序指令**——手仍在顶点时,髋先行旋转
  3. 绿色打折竖带 | 锚:躯干 | 语义:正确形状——身体后折下蹲、臀后移,为下杆让出空间
- **三秒读法(专家)**:"手别先动;髋先转、身体下坐,手最后跟"
- **三秒读法(素人,实测)**:只读出 1 和 3 的一半——**时序语义静态图承载力不足的实证**
- **有效原理**:多元素分工(错误处/启动处/形状),但静态呈现时序天然吃力
- **单主体迁移**:时序类句型 → **动画原生表达**(见 §3 法则9),静态版本降级为多元素组合

### Image_20260602214124_120_1.jpg
- 真值落定:髋部平移(红直箭头,错)vs 髋部旋转(绿弧箭头,对),下杆时刻
- 与 _181(侧移/转动)、_122 族并列,**箭头形状字典三重互证**:直=平移,弧=旋转

### Image_20260602214257_191(HandyGolf 顶点绿箭头)

## 2. IDL Schema v0.2 变更

**语义角色维度新增:「时序指令」「时序错误」**(源:_119)
错误运动学分类新增第四类:
1. 角度类(楔+线+弧箭头)
2. 越线类(栅栏+点+直箭头)
3. 形变类(圈+夹合箭头 / 形状线)
4. **时序类(动画原生:先动部位的箭头先动,后动部位标记静止)** ← 新增

原语表(累计):
P1 正确区 / P2 现状线 / P3 方向箭头 / P4 关节圈+夹合箭头 / P5 栅栏线 / P6 幽灵参照(高级层) / P7 正确形线 / **P8 运动语义箭头字典(直=平移,弧=旋转,对向=收拢;颜色极性=指令极性,强制校验;形态:细窄,不遮身体)** / P9 关节角度弧 / P10 部位淡色块 / P11 区域注意圈(不得单独成图) / P12 形状词(Y/三角/C)

## 3. 设计语言法则(累计至法则9)

1. 前注意承载,文字只作命名徽章与裁决徽章
2. 箭头即动词(Tversky),但箭头歧义必须消解
3. 禁用"缺失式"cue,错误必须画成存在物
4. 一图一对比
5. 外部焦点 + 低频反馈(Wulf / guidance hypothesis)
6. 色盲冗余:灰度下位置与形状仍讲完整故事
7. (修正)禁调试风格全身骨架;经设计的局部关节链+白圈节点是合法用户语言(_122、wrist control 系列为证)
8. 身体是主角:不压暗人物、不遮挡躯干;聚焦手段=自发光线条、尺寸、SAM2 背景压暗、淡色块
9. **动态优先(Jason 拍板)**:指示器默认动画呈现;静态为降级形态。**动效预算=1**——每 cue 仅一个运动元素(指令箭头),现状线与正确形线静止。依据:运动是最强前注意属性;动画消解箭头歧义(演示而非象征);共同命运原则将运动绑定到部位;时序类错误只有动画能自然表达

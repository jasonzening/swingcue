## 方向约定

- 球手：右手持杆（all five videos）  
- 正面机位（face-on）：目标侧 = 画面右侧（golfer faces camera, target is to golfer's left = screen right）  
- DTL 机位：球侧 = address 帧 `wrist_mid_x > hip_mid_x` 方向（已在 C 层 FeatureExtractor 中按此约定执行）  
- 头部横向位移符号：`+` = 画面右 = 目标侧；`-` = 画面左 = 后侧  
- 头部纵向位移符号：`+` = 头部上移；`-` = 头部下移  
- 髋部 hip_disp：`+` = hip_mid_x 向球侧位移（fraction of torso_h）  
- 脊柱 spine_delta：`+` = 前倾角减小（脊柱变直）；`-` = 前倾角增大

## 注释

1. **全部五段均不含教科书 Early Extension**（EE 全阴性）。  
   201054 / 201058 引擎输出"未检出明显问题"为真阴性。

2. **LoP 待定说明**：201039 / 201047 存在头部上移测量值（+25.9% / +14.6%），  
   但 FAULT_VISUAL_STANDARDS v0.2 §2 明确：**Loss of Posture 主诊断机位为 DTL**，  
   正面机位为辅助。这两段视频的 DTL 脊柱角数据尚未获取，待 DTL 视频补录后再定性。

3. **鸡翅窗口修正**（per v0.2 §3）：  
   原固定 impact+8 窗口过宽；修正为动态截止：  
   `cutoff = impact 后第一个 wrist_mid_y < hip_mid_y 的帧`（手腕高过髋线即出窗）。  
   修正结果：  
   - 201015：窗口 fr59–fr61（3帧），elbow_min fr61 = **171.0°**  
   - 201039：窗口 fr205–fr208（4帧），elbow_min fr207 = **162.5°**  
   - 201047：窗口 fr277–fr279（3帧），elbow_min fr279 = **149.6°**  
   注：fr282 在旧固定窗口内但**不在**修正窗口内；修正后的 149.6° 仍符合鸡翅形态特征。

4. **201015 录制缺陷**：该视频直接从下杆开始，反杆过程不在画面内，  
   导致 address 帧即为 fr49（起始帧），top 帧与 address 重合。  
   头部下沉 -10.3% 为下蹲动作，属五种预定缺陷之外的独立现象，如实记录备查。

5. **GT 铁律**：本档所有标签均由人工确认写入。  
   Hermes 测量报告（gt_measure/）为纯数字，无缺陷标签。  
   任何引擎代码不得将本档标签用于训练或直接反向调整阈值——  
   阈值调整需另起任务、经人批准。

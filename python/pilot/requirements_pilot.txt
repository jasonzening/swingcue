# Phase 2 bone-center pilot — LOCAL DEV dependencies.

# These are the deps Jason installs in a venv on his laptop to run

# Images themselves — those have their own dependency trees defined per
# library in modal_app.py.

# Recommended setup (separate from .venv-benchmark and from production):
#
#   python3.11 -m venv .venv-pilot
#   .venv-pilot\Scripts\Activate.ps1     # (PowerShell on Windows)
#   pip install -r python/pilot/requirements_pilot.txt
#   modal token new                       # browser login, writes ~/.modal.toml
#
# After that, scaffold sanity-check:
#
#   python -m python.pilot.modal_app

TAR-ViTPose 安装失败记录
======================================================

卡点: mmcv 无法在本环境安装

环境条件:
  OS: WSL2 (Ubuntu)
  Python: 3.12.3
  PyTorch: 2.6.0+cu124
  CUDA Runtime: 12.4 (via /usr/lib/wsl/lib)
  CUDA Toolkit: 未安装 (无 nvcc, 无 cuda.h)

依赖链:
  TAR-ViTPose → mmpose.apis.init_model
             → mmpose >= 1.3.1
             → mmcv >= 2.1.0 (需要 CUDA kernel 编译)

失败原因:
  1. mmcv 没有 cu124+torch2.6 的预编译 wheel
     (openmmlab 只提供到 cu121/torch2.4)
  
  2. mmcv 源码编译需要 CUDA Toolkit (nvcc)
     WSL 只有 CUDA 运行时库，没有开发工具链
     报错: OSError: CUDA_HOME environment variable is not set
  
  3. 即使解决 mmcv，TAR-ViTPose 还需要:
     - mmpose 1.3.1 (同样依赖 mmcv)
     - timm (ViT backbone)
     - ultralytics (YOLOv11 检测器)
     - 从 Google Drive 手动下载权重文件

已尝试方法:
  - uv pip install mmcv (binary): 404 - 无对应版本
  - uv pip install mmcv --no-binary (源码): nvcc 缺失
  - 设置 CUDA_HOME: 无效，nvcc 本身不存在

跳过原因:
  超过 2 小时限制前已明确判断不可行，记录卡点。
  TAR-ViTPose 是 2026 CVPR Highlight，设计用于训练集群，
  不适合无完整 CUDA Toolkit 的 WSL 推理环境。

如果要在未来跑通，需要:
  A. 安装 CUDA Toolkit 12.x: 
     sudo apt install cuda-toolkit-12-4
     (或通过 runfile 安装，WSL 下需要 --no-kernel-module)
  B. 或使用已有 mmcv 预编译 wheel 的环境 (torch<=2.4 + cu121)
  C. 或等 TAR-ViTPose 官方发布 ONNX/TensorRT 导出版本

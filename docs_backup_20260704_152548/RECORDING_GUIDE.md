# RECORDING_GUIDE.md — 挥杆视频拍摄引导

> 拍摄质量直接决定识别效果——视频拍得差,后面算法怎么修都很痛苦。补拍测试集、以及将来 App 引导用户拍摄,都按本指南。依据主文档 4.6。

## 通用要求(正面侧面都适用)

- **手机固定,不手持**(支架/倚靠稳固物),避免晃动——不在软件层对抗手持抖动,用拍摄纪律解决
- 人**全身入镜**,球杆尽量全程入镜
- **一次只拍一杆**,画面里只有一个人,无他人走动
- 光线充足、均匀;背景尽量干净
- 球的位置尽量可见(便于核对 impact)
- 帧率尽量高(≥60fps 更利于捕捉高速击球;30fps 可用)

## 侧面 down-the-line(看挥杆平面、脊柱角、手腕)

- 相机放在**目标线后方或略偏后方**,沿目标线方向看出去
- 相机高度约**腰到胸之间**
- 能同时看到身体侧面和杆身轨迹

## 正面 face-on(看旋转、轴心、重心、侧移)

- 相机站在**球线正侧方**(正对球员胸口方向)
- 相机高度约**胸口高度**
- 能看到双肩、双髋的左右展开

## 测试集需求(给 PhaseDetector / 指示器做 5 段验收)

- 正面、侧面**各至少 5 段**
- 尽量覆盖:不同的人 / 不同球杆 / 不同清晰度 / 不同水平
- 放入 `input/test_set/faceon/` 和 `input/test_set/dtl/`
- 文件名建议:`faceon_01.mp4`、`dtl_01.mp4` …

## 拍砸了的信号(出现就重拍)

- 关键点检测置信度整体偏低 → App 会提示重拍
- 人体出框、严重逆光、画面晃动、一镜多杆/多人
